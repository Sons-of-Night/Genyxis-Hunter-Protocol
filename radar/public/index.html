Coverage and Limitations

Honest operational scope for a commercial security service

What is live

Solana mainnet WebSocket logs for all non-vote transactions supplied by the configured RPC, independent watched-address streams, chain slot health, and operator-defined policy matches.

What is not claimed

This is not comprehensive historical indexing, an audited malware detector, AI-agent attribution, wallet custody, network censorship, or guaranteed prevention of attacks.

Coverage gaps

Provider throttling, dropped WebSocket messages and connection outages can cause missing events. Real production monitoring needs durable streaming and backfill, such as Yellowstone gRPC.

Pre-transaction protection

The read-only assessment API can recommend denial for configured addresses. To actually stop a user from authorizing a transaction, an integrated wallet or dApp must act on that result.

Server binds to loopback. It never asks for wallet seed phrases or changes the existing Genyxis validator, keys, ledger, or PostgreSQL state.
